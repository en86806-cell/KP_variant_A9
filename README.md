## индивидуальный вариант
**Вариант А9. Генератор — напряжение**
*   **Датчик:** Напряжение, В (Вольт).
*   **Параметр X:** Значение напряжения.

## Математическая модель 
Формула для расчета Q(x) (кусочно-заданная функция):

$$
Q(x) = 
\begin{cases} 
1.2x, & \text{при } x < 180 \\
0.9x + 54, & \text{при } 180 \le x \le 230 \\
0.6x + 123, & \text{при } x > 230 
\end{cases}
$$

## Оперативный контроль
*   **Тип контроля:** Тип C
*   **Базовое значение:** \(Q_0 = 240\)
*   **Предельное значение:** \(S_{max} = 250\)

## Статистический анализ
Для выборки значений Q необходимо вычислить:
1. Среднее значение.
2. Дисперсию.
3. Размах (Max - Min).
4. Число значений в пределах \(\pm 5\%\) от среднего.

## Ручной расчет (2-3 значения)
Для проверки возьмем по одному значению из каждого интервала:

*   **x = 100** (меньше 180):
    Подставляем в первую формулу: \(Q = 1.2 \cdot 100 = 120\).
    
*   **x = 200** (попадает во второй интервал 180...230):
    Подставляем во вторую формулу: \(Q = 0.9 \cdot 200 + 54 = 180 + 54 = 234\).
    
*   **x = 250** (больше 230):
    Подставляем в третью формулу: \(Q = 0.6 \cdot 250 + 123 = 150 + 123 = 273\).
